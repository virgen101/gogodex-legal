# GogoDex — Yasal metinler

Bu depo yalnızca GogoDex uygulamasının **gizlilik politikasını** barındırır.
Uygulamanın kaynak kodu burada DEĞİLDİR ve herkese açık değildir.

- [Gizlilik Politikası (Türkçe)](https://legal.gogodex.app/gizlilik)
- [Privacy Policy (English)](https://legal.gogodex.app/privacy)

Metinler GogoDex deposundaki `docs/` klasöründen üretilir
(`scripts/publish-legal.sh`); burada elle düzenlenmemelidir.
